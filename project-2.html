Contexte

Un acteur e-commerce en croissance avait besoin de sécuriser son tunnel d'achat face aux nouvelles livraisons de fonctionnalités hebdomadaires. Les tests manuels de régression prenaient 2 jours pour 2 testeurs. L'objectif : automatiser 85% des scénarios critiques en moins de 15 minutes d'exécution.

Architecture du framework

Le framework repose sur le pattern Page Object Model (POM) avec Cypress 12 :

  • cypress/pages/ — abstractions des pages (HomePage, ProductPage, CartPage, CheckoutPage)
  • cypress/fixtures/ — données de test (produits, utilisateurs, adresses)
  • cypress/support/ — commandes custom (login, addToCart, checkout)
  • cypress/e2e/ — specs organisées par feature (catalogue, panier, paiement, compte)

Exemple de test

// cypress/e2e/checkout/full-purchase.cy.js
import { CartPage } from '../../pages/CartPage'
import { CheckoutPage } from '../../pages/CheckoutPage'
import products from '../../fixtures/products.json'

describe('Tunnel d\'achat complet', () => {
  beforeEach(() => {
    cy.login('test@example.com', 'password123')
  })

  it('doit permettre d\'acheter un produit', () => {
    cy.visit('/products')
    cy.addToCart(products.laptop.id)

    const cart = new CartPage()
    cart.open()
    cart.assertItemCount(1)
    cart.assertTotal(products.laptop.price)
    cart.proceedToCheckout()

    const checkout = new CheckoutPage()
    checkout.fillShipping(Cypress.env('TEST_ADDRESS'))
    checkout.selectPayment('card')
    checkout.fillCard('4111 1111 1111 1111', '12/26', '123')
    checkout.submit()

    cy.url().should('include', '/order-confirmation')
    cy.contains('Commande confirmée').should('be.visible')
  })
})

Intégration CI/CD

Le workflow GitHub Actions exécute les tests en parallèle sur 4 containers Cypress :

name: E2E Tests
on: [push, pull_request]
jobs:
  cypress-run:
    strategy:
      matrix:
        containers: [1, 2, 3, 4]
    runs-on: ubuntu-latest
    steps:
      - uses: cypress-io/github-action@v6
        with:
          record: true
          parallel: true
          group: 'E2E Tests'
        env:
          CYPRESS_RECORD_KEY: ${{ secrets.CYPRESS_RECORD_KEY }}
